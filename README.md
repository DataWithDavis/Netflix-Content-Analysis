# Netflix-Content-Analysis
End-to-end Netflix content analysis using Python, MySQL, and Power BI, uncovering trends in content distribution, genres, countries, and ratings.

## 🎯 Business Objective

The main objective of this project is to analyze Netflix's content catalog and identify meaningful patterns that can help understand:

- Content distribution between Movies and TV Shows
- Content growth over time
- Countries contributing the most titles
- Most represented genres
- Distribution of content ratings
- Geographic and content trends
